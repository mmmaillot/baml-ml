# MacBook Pro baseline · 2026-11-27

MacBook Pro, Apple M1 Pro (8 performance + 2 efficiency cores), 32 GB RAM,
macOS 27.2.1 (26B131), ARM64, on AC power. BAML 0.26.0, Python 3.12.1,
scikit-learn 1.8.0, NumPy 2.5.5 and SciPy 1.18.1. Inference sources at
`9916a103da22`.

Iris multinomial logistic regression, `predict-proba`, with the same fitted
pipeline and identical JSON input batches. 15 samples per combination after warmup.
The largest absolute probability difference was 2.2e-16. The ARM64
standalone executable is 34,570,962 bytes (32.97 MiB).

## Launch and loaded model

The median `--help` launch took 22.6 ms for BAML and 881.9 ms for the Python job
with its dependencies imported. This is a separate launch reference.

The table reports median milliseconds per inference request for a loaded
model, with three untimed warmup calls and telemetry off in BAML.

BAML had lower end to end latency for all three process sizes. With both
models loaded, BAML was faster at one row and scikit-learn was faster at
128 and 4,096 rows. Timing and semantic each added roughly 80 ms to
standalone wall time across the tested sizes. Full recording size grew with
the batch.
