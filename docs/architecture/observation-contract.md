# Native inference observation contract v1

Status: initial implementation, CI validation pending. Applies to loaded
LinearRegression and LogisticRegression models, not the legacy checked
stateless helper API or arbitrary caller instrumentation.

## Native capture modes

Pass observation = ObservationMode.Semantic (default), Full, or Timing
to LoadLinearModel, LoadLogisticModel, PrepareLinearModel or PrepareLogisticModel.
Policy is fixed for that loaded handle.

| Mode | Runtime semantic spans | Values | Aggregate profiler |
|---|---|---|---|
| Timing | No | No | Yes |
| Semantic | Yes | No | Yes |
| Full | Yes | Inputs, outputs and typed errors | Yes |
| BAML_TELEMETRY=off | No | No | No |

The first three use native trace.Options (timing, empty_span, span) at the
runtime's call sites. BAML_TELEMETRY=off is the engine-wide native override.
Semantic is deliberately the default: explicit opt-in to numerical payloads.
A caller's root, manually traced calls, or other application code can still
capture values; these modes are not global privacy controls. No custom
telemetry emitter, collector, exporter or storage layer is introduced.

```baml
let model = LoadLogisticModel("model.json", observation = ObservationMode.Full);
let p = model.predict_proba(rows, names,
  $trace = trace.context(distinct_id = "request-42"));
```

The native context is inherited by the prediction and its children. The
caller may provide distinct_id or other application metadata. Native span
IDs identify individual invocations; no invented globally unique request
ID is generated by the library.

## Stable boundaries

Native span names include the user. prefix. Contract metadata keys:
baml_ml.contract_version (1), baml_ml.model_id, baml_ml.schema_version and
baml_ml.source_version (sklearn version, not a separately managed model revision).
model_id is the artifact identity supplied by its exporter, not authentication.

| Semantic span | Full inputs | Full output |
|---|---|---|
| PrepareArtifact | None (raw JSON suppressed) | None; errors on invalid preparation |
| ModelLoaded | Validated fitted artifact | void |
| PredictLoadedLinear / PredictLoadedProba / PredictLoadedLabels | Model ID, ordered feature names and input rows | Existing result object on success |
| ObservedImpute | Raw rows | Imputed rows |
| ObservedScale | Imputed rows | Standardized rows |
| ObservedLinear | Standardized rows | Regression values |
| ObservedDecisionScores | Standardized rows | Decision score matrix |
| ObservedSoftmax | Decision score matrix | Probabilities |
| ObservedLabels | Decision score matrix, ordered classes | Integer labels |

Prediction stages are children of the prediction span; intermediate helper
functions are timing-only by default. Label-only inference does not perform
softmax. Binary decision scores are [0,z] (the second score is sklearn's
decision function); multiclass scores follow artifact class order.

Prepared pipeline/parameter arguments are wrapped in a native @trace.redact
field for semantic inference spans. The full model artifact is captured in
ModelLoaded once per load. This is a guarantee about these semantic payloads,
not total storage deduplication, nor an assertion that the underlying BAML
root or arbitrary caller spans cannot capture a copy of the parameters.
Retain the load recording or artifact alongside any prediction that refers
to it; cross-recording retention and indexing policy is not implemented.

## Failure semantics

Prediction calls raise a typed InferenceFailure inside the traced semantic
boundary. It carries stage and message. The public closure catches it and
returns the existing ok:false result with the original error text. Thus the
semantic span is a failure even though the public method returns normally.
Stages include input_validation, imputation, standardization,
linear_prediction, decision_scores and softmax. Later stages are not called
after a failed stage. Full captures error values; Semantic captures status
without payload; Timing relies on native outcome counters.
Malformed JSON, unsupported or invalid artifact state fail in PrepareArtifact;
file-read errors propagate from Load* and are not yet a named contract span.
Unexpected engine failures are not swallowed by the library.

## Tests and operational boundaries

The imported-inference harness executes unmodified runtime sources, queries
native recordings and checks values, parent IDs, model identity/context,
redaction, all three successful reference models, label-only execution,
invalid feature ordering, infinite input, overflow, invalid load and policy
modes. Repeated-call profiler check still requires one preparation for three
predictions. The historical native observability harness remains a separate
experiment using low-level functions.

The contract does not include drift computation, dashboards, a collector,
per-request sampling, remote export, retention, access control or
cross-process model lifetime. A production deployment must explicitly
evaluate root/caller trace policies, local storage and data handling before
enabling full capture on real inputs. No performance claim until measured.
